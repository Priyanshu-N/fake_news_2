# Fake News Detection System

## Overview

This project explores the classification of news articles as fake
or real using Natural Language Processing and machine learning.

The goal is to build an understandable text-processing pipeline,
train classification models, and evaluate their performance.

## Planned Development

- Dataset inspection and validation
- Text preprocessing
- Text feature extraction
- Model training
- Model evaluation
- Prediction interface

## Technologies

- Python
- Natural Language Processing
- pandas
